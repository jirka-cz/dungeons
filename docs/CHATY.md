# Jak pokračovat v nových chatech

Velký chat se rozděluje na menší, jeden chat = jedno téma. Všechny patří do Claude projektu **World & Dungeons**. Kód a dokumentace jsou na GitHubu, takže každý chat začne s aktuálním stavem.

## Instrukce projektu (vložit do „Set project instructions“)

```
Pracujeme na hře World & Dungeons – 2D akční RPG v prohlížeči (styl Diablo 3), které vytvářím jen přes zadání. Neprogramuju, piš mi česky a srozumitelně.

Kód je v GitHub repozitáři jirka-cz/dungeons (větev main). Na začátku každého chatu si repozitář stáhni a přečti PROJEKT.md a dokument tématu z docs/. Postupuj podle sekce „Jak pracovat“ v PROJEKT.md: měň jen to, co zadám, otestuj, zvyš verzi, aktualizuj dokumentaci a změny pushni do main (GitHub Pages se aktualizuje sám). Rozhodnutí v PROJEKT.md neměň bez mého souhlasu.
```

## Úvodní zprávy pro jednotlivé chaty

Stačí zkopírovat první řádek a dopsat, co chceš udělat.

| Chat | Úvodní zpráva |
|---|---|
| Talenty | `Téma: talenty (docs/talenty.md). Chci…` |
| Postavy | `Téma: postavy, rasy, třídy a dovednosti (docs/postavy.md). Chci…` |
| Město | `Téma: město, obchod, kovář, truhla (docs/mesto.md). Chci…` |
| Dungeony | `Téma: rifty, nepřátelé, bossové, obtížnost (docs/dungeony.md). Chci…` |
| Předměty | `Téma: předměty, kořist, sety, legendárky (docs/predmety.md). Chci…` |
| Rozhraní | `Téma: ovládání, HUD, okna, mobil (docs/rozhrani.md). Chci…` |
| Technika | `Téma: ukládání, testy, nasazení, výkon (docs/technika.md). Chci…` |

## Tipy
- Když chat začne být dlouhý (Claude ho začne automaticky shrnovat), je čas založit nový ke stejnému tématu. Nic se neztratí – stav je v repozitáři.
- Drobnost, která se netýká žádného tématu, patří do chatu „Technika“, nebo do nového krátkého chatu.
- Když se změní rozhodnutí (např. „přidej strop úrovně“), stačí to říct. Claude upraví i PROJEKT.md, aby o tom věděly další chaty.
